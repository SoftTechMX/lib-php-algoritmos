# Algoritmos

Este  repositorio  es  un  paquete  PHP  para  packagist el cual contiene clases 
relacionadas con algortimos de ordenamiento.

La idea es tener una implementacion  de  los  algoritmos mas famosos en una sola 
clase, disponible para  ser  instanciada  y  usada  en cualquier proyecto usando
composer 2.

Para instalar mediante coposer ejecuta el siguiente comando
```bash
composer require soft-tech-mx/algoritmos
```
